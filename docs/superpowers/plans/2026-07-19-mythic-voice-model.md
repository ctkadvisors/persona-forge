# Mythic-Voice Shareable Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax. This plan is intentionally lean (executed inline by its author immediately after writing); interfaces are binding, code detail lives in the commits.

**Goal:** Legally shareable world-agnostic mythic-voice 9B model per `docs/superpowers/specs/2026-07-19-mythic-voice-shareable-model-design.md`.

**Global constraints:** persona-forge stays generic (no private data, no protected names — including in tests); private inputs (teacher endpoint, corpus, blocklist) are runtime parameters supplied on the Spark from tolkien-llm. Student `Qwen/Qwen3.5-9B`. Leakage eval must pass 100% to ship. No HF publication without explicit user go-ahead post-beta. Tests: `python -m pytest -q` green in persona-forge.

## Tasks

- [ ] **1. `personaforge/decontam.py` (TDD)** — `Decontaminator(corpus_text: str, blocklist: list[str], n: int = 8)`; `check(text) -> tuple[bool, str]` (reason ∈ ok|ngram_overlap|blocklist:<word>); word-boundary, case-insensitive blocklist; n-gram gate on lowercase word sequences shared with corpus; `report() -> dict` cumulative pass/drop counts by reason. Tests: overlap detected at exactly n words, not at n-1; blocklist word-boundary (no substring false hits); report counts.
- [ ] **2. `packs/mythic.json` + `personaforge/data/exemplars.py`** — 8 archetype cards with original invented names (Vaelric the Wanderer, Serwen the Shieldmaiden, Brammond the Smith, Ythel the Loremother, Durnhal the Ferryman, Maerwen of the High Vale, King Othmar, Talvi the Star-Reader), world "an old world of myth and deep roads", 12+ scenarios, standard provocations; validates via `python -m personaforge.pack`. exemplars.py: short public-domain style passages (Malory, Morris, KJV cadence) + `exemplar_block()` helper. Test: pack validates; exemplars non-empty and free of blocklist-style coinages.
- [ ] **3. `personaforge/data/voicegen.py` (TDD)** — `QUESTION_BANK` (~40 original modern questions), `TALE_PROMPTS` (~16), `gen_register_chat(teacher, judge, questions, style_block="") -> sft rows` (kind "chat", source "register_chat"), `gen_tales(teacher, judge, prompts, style_block="") -> sft rows` (source "tales"), `gen_register_dpo(teacher_hi, teacher_plain, judge, questions) -> dpo rows` (chosen in-register, rejected deliberately plain-modern), `judged_pick(candidates, judge, threshold=0.7)` two-teacher selector. All judge-filtered ≥ 0.7 voice.
- [ ] **4. `personaforge/eval/leakage.py` (TDD)** — `build_probes(blocklist, paraphrase_traps) -> list[dict]` (name probes "Who is X?"/"Tell me of X" from runtime blocklist; public paraphrase traps like the ring-in-the-fire tale ship in-module; completion probes read from optional private file), `score_leakage(items, blocklist, judge) -> dict` (fail on blocklist hit in reply OR judge-recognized protected-work content; returns pass_rate, failures list). Test with fake judge + tiny blocklist.
- [ ] **5. `personaforge/build_voice.py`** — staged runner mirroring tolkien-llm's build_grounded: STAGE=teacher_a (slow tuned teacher via TEACHER_A model name; decontam applied with CORPUS+BLOCKLIST files) | STAGE=full (teacher B + judge via exemplars, merge judged pools, pack roleplay/provocation/assignment gens, blend, write OUT_DIR datasets + provenance.json with teacher mix, decontam report, volumes). Env: PACK, OUT_DIR, N_CHAT, N_TALES, N_RP, N_DPO, TEACHER_A, TEACHER_B, JUDGE, CORPUS, BLOCKLIST.
- [ ] **6. Private: blocklist** — tolkien-llm `scripts/build_blocklist.py`: manual seed list (major coinages incl. PD-origin names, conservative over-block) + capitalized-token frequency extraction from `data/raw/tolkien.txt` (freq ≥ 5, not in English wordlist), curated output `data/blocklist.txt` (gitignored dir). Sanity: ≥ 200 entries, contains seeds.
- [ ] **7. Spark: generate** — sync persona-forge to Spark (`~/persona-forge`, container-visible mount strategy: run inside tolkien-dev with PYTHONPATH), STAGE=teacher_a with `tolkien` loaded (llama-swap), then STAGE=full with gemma. Spot-check outputs + provenance.json.
- [ ] **8. Spark: train** — persona-forge `train_run`: CPT on gutenberg concat, SFT+DPO on the blend, MODEL_ID=Qwen/Qwen3.5-9B (models unloaded during training per standing approval). Monitor.
- [ ] **9. Spark: eval** — battery (two-phase if needed; 9B + gemma likely co-resident) + leakage eval vs blocklist. Gates: battery per pack-smoke thresholds, voice ≥ 0.75, leakage 100%.
- [ ] **10. Merge + quantize** — merge_export → bf16 → GGUF q8 (`--no-mtp` N/A for 9B dense — verify header anyway) + MLX q4 (Spark mlx-venv; qwen3_5 shim only if config says qwen3_5_text). Provenance report finalized.
- [ ] **11. Deliver** — beta artifact to the Mac (LM Studio dir, NOT auto-loaded), MLflow registration (new registered model `mythic-voice-9b`, run + provenance artifact), report to user. HF release deferred to user go-ahead.
